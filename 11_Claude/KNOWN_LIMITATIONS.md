# 已知限制说明

> 城市分时电价观察站 MVP — 当前版本已知限制和后续建议

---

## 一、数据层面的限制

### 1. 部分价格为推算值而非官方绝对数值

各省发改委的政策文件通常仅规定浮动比例（如"高峰上浮 65%"），但不直接公布平段基准价的绝对数值。本项目中部分具体电价（尤其是标为 `estimated` 的数据）基于以下方式推算：

- 参考行业媒体（北极星售电网、中国储能网等）公布的各省平段参考价
- 结合国家电网每月公告的代理购电价格表
- 使用各省已公布的输配电价和基金附加标准

**影响**：具体金额可能与实际结算电价有偏差，建议用于趋势对比而非精确计费。

### 2. 内蒙古数据仅有蒙西和蒙东电网通用政策

内蒙古地域辽阔，蒙西电网（覆盖呼和浩特、包头等）和蒙东电网（覆盖赤峰、通辽等）的分时电价政策存在差异。当前版本仅收录了自治区级的通用工商业分时电价政策，具体到各盟市可能有地方补充细则。

### 3. 居民和农业用电分时电价覆盖不全

山东已试点居民分时电价（谷段低至 0.37 元/kWh），其他省份的居民和农业用电分时电价数据尚不完整，已标注为缺失。

### 4. 代理购电价格按月变动

工商业用户的代理购电价格（平段基础电价的重要组成部分）由各省电网公司按月发布，本数据库未实现自动同步更新，静态 CSV 文件中使用的为参考值。

## 二、技术层面的限制

### 1. SQLite 模式下需要额外启动服务

CSV 模式纯静态可直接打开，SQLite 模式需要：
1. 运行 `python3 init_db.py` 初始化数据库
2. 运行 `python3 server/app.py` 启动 API 服务（默认端口 3456）

如果端口被占用或 Python 环境不完整，SQLite 模式无法正常工作。

### 2. CORS 限制

CSV 模式通过 `fetch()` 直接读取本地文件时，在某些浏览器（如 Chrome）的安全策略下可能需要 `file://` 协议配置或使用 `--allow-file-access-from-files` 标志。建议使用 **VS Code Live Server** 或 **Python HTTP 服务器** 来打开页面：

```bash
cd 06_XWork
python3 -m http.server 8000
# 然后访问 http://localhost:8000/11_Claude/index.html
```

### 3. 静态页面的动态筛选能力有限

当前版本使用纯前端 Chart.js 渲染曲线图，所有数据预加载到内存中进行筛选。当数据量大幅增长（如扩展到 30+ 省份）时，页面加载和筛选性能可能下降。

### 4. 无搜索功能

当前版本不支持关键词搜索，用户需要通过导航和筛选查看数据。搜索功能建议在后续版本中实现。

### 5. 移动端适配

虽已适配移动端布局，但曲线图表在手机小屏上的交互体验（尤其是多点触摸和缩放）还有优化空间。

## 三、数据来源层面的限制

### 1. 部分官方来源被 WAF 防护

在数据采集过程中，北极星售电网 (bjx.com.cn) 等网站使用了阿里云 WAF 防护，导致自动采集失败。这些站点的内容通过其他渠道（如微信公众号、转载站点）获取。

### 2. 官方 PDF 文件未结构化

部分省市的电价公告以 PDF 附件形式发布，其中的电价表格需要人工或 OCR 转写为结构化数据，可能存在格式转换误差。

### 3. 未使用代理购电价格实时接口

各省电网公司每月在官网和"网上国网"APP 发布当月的代理购电价格表，但本 MVP 未对接这些实时数据接口。

---

## 四、功能层面的限制

### 1. 无用户交互功能

当前版本为只读展示页面，不支持用户保存筛选条件、导出数据、订阅价格变动通知等功能。

### 2. 无历史数据对比

仅展示当前生效政策的电价数据，不支持同一省份不同年份的政策对比或历史趋势分析。

### 3. 无电价计算器

不支持用户输入用电参数（用户类型、电压等级、用电时段等）来计算预估电费。

---

## 五、后续建议

### 短期（MVP 范围外但可快速实现）

1. **对接代理购电价格接口**：如能获取电网公司每月公告的结构化数据，可显著提升价格准确性
2. **扩展至更多省份**：当前 5 省验证链路，后续可扩展至全国 31 个省/市/自治区
3. **增加行政区划细化**：从省级下沉至地市级，特别是深圳、苏州等电价政策独立执行的计划单列市
4. **数据导出功能**：增加 CSV/Excel 导出按钮，方便用户下载分析

### 中期

1. **后端用户系统**：支持用户注册、收藏、价格预警
2. **自动化数据更新管道**：定期检测各省发改委/电网公司官网的政策更新，自动提醒数据维护人员
3. **电价计算器**：基于用户输入的负荷曲线和选择的省份/用户类型，估算分时电价总费用

### 长期

1. **接入电力现货市场价格**：展示日前市场/实时市场的价格波动
2. **AI 辅助分析**：基于历史电价数据预测未来时段价格趋势
3. **多维度对比**：支持跨省、跨用户类型、跨时间维度的自定义对比
