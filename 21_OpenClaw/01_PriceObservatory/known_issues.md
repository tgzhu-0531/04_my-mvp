# 已知限制说明

## 1. 数据范围限制

### 1.1 仅覆盖5省
- 当前 MVP 仅覆盖广东、江苏、山东、浙江、内蒙古 5 个省区
- 其他省份如四川、湖北、北京等尚未纳入
- 每个省仅采集了1种用户类型（一般工商业 1-10kV）的数据

### 1.2 季节性数据不完整
- 广东省：包含夏季（7-9月）和非夏季时段的完整数据
- 山东省：包含夏季（6-8月）和冬季（12-2月）数据
- 江苏省、浙江省、内蒙古：仅包含全年统一时段数据
- 部分省份尖峰/深谷时段的具体起止时间仍需进一步核实

### 1.3 价格精确度
- 当前价格数据为主要类别（一般工商业 1-10kV）的代理购电基准价
- 实际用户结算价格还包含输配电价、政府基金及附加等，此版本暂未累加
- 各省月度代理购电价格可能小幅波动，本数据采集日为2025-07-01

## 2. 数据源限制

### 2.1 原始文件获取
- 部分省份发改委官网的文件归档页面无法直接访问历史政策文件
- 电网公司公布的代理购电价格表每月更新，旧月份价格表归档不全
- 本数据来自公开可访问的官方网站，但个别文件的精确页面 URL 可能需要通过站内搜索获取

### 2.2 数据验证
- 当前数据由 AI 助手通过公开渠道整理，未经各省发改委书面确认
- 交叉验证仅限官方网站公布的 PDF/HTML 格式文件
- 部分省份存在多个版本的政策文件，价格以最新公告为准

## 3. 技术限制

### 3.1 CSV 模式限制
- CSV 模式为静态前端方案，不支持后端实时查询
- 数据筛选和排序完全在浏览器端完成，大数据量时性能可能下降
- 不支持跨数据源动态关联查询

### 3.2 SQLite 模式限制
- SQLite 数据库模式运行需要 Python 环境（Python 3.6+）
- 需要启动本地 API 服务（server/api.py），监听 8080 端口
- 不适合生产环境的高并发访问
- 不支持多用户并发写入

### 3.3 前端限制
- 图表仅使用 Chart.js，自定义图表类型有限
- 未实现移动端完全响应式适配（MVP阶段以桌面端为主）
- 未实现数据导出功能（建议未来迭代添加）

## 4. 业务逻辑限制

### 4.1 价格计算
- 当前仅展示目录电价（平段价格），未计算实际结算价格
- 未包含基本电费（需量/容量）的计算
- 未包含力调电费调整

### 4.2 时段对比
- 不同省份的时段划分标准不同（如广东的"尖峰"仅夏季存在）
- 标准分类（尖峰/高峰/平段/低谷/深谷）为映射后的统一分类，可能与原始文件命名不完全一致

## 5. 后续改进建议

1. **数据扩展**：增加更多省份、更多电压等级、更多用户类型的数据
2. **自动更新**：建立定期自动抓取机制，跟踪政策变化
3. **价格计算器**：根据用户用电量模拟电费对比
4. **历史回溯**：收集和展示历史价格变动趋势
5. **移动端适配**：完善移动端和触摸屏的交互体验
6. **数据导出**：支持导出为 Excel/PDF 格式
