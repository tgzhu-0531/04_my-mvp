# 术语表

## 电价相关术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 分时电价 | Time-of-Use (TOU) Pricing | 根据电网负荷变化，将一天划分为不同时段，各时段执行不同电价水平的定价机制 |
| 峰谷电价 | Peak-Valley Pricing | 分时电价的一种，将一天划分为高峰、平段、低谷时段 |
| 尖峰电价 | Peak Pricing (Premium) | 在高峰时段基础上，进一步划分出用电尖峰时段，执行更高电价 |
| 高峰时段 | Peak Period | 电网负荷较高的时段，执行较高电价 |
| 平段时间 | Flat Period | 电网负荷一般的时段，执行基准电价 |
| 低谷时段 | Valley Period | 电网负荷较低时段，执行较低电价 |
| 深谷时段 | Deep Valley Period | 在低谷时段基础上，用电负荷极低时段，执行更低电价 |
| 一般工商业 | General Industry & Commerce | 指除大工业用户外的工商业电力用户 |
| 大工业 | Large Industry | 指受电变压器容量在315kVA及以上的工业生产用户 |
| 代理购电 | Agency Power Purchase | 电网企业代理未直接参与市场化交易的工商业用户购电 |
| 电压等级 | Voltage Level | 用户接入电网的电压等级（如1-10kV、35-110kV等），影响电价水平 |

## 数据相关术语

| 术语 | 说明 |
|------|------|
| 数据源 | 原始数据来源，包括政府部门文件、电网公司公告等 |
| 数据可信度 | high/medium/low 三级评估，high 为官方文件直接获取 |
| 数据缺失 | 因政策未覆盖、数据未公开等原因缺失的数据项 |
| 时价曲线 | 按时间轴展示的分时电价变化趋势图 |
| 价差比 | 峰时段电价与谷时段电价之比，反映价格调节力度 |
| 原始时段名称 | 各份政策文件中实际使用的时段名称 |
| 标准分类 | 本项目统一使用的时段分类（尖峰/高峰/平段/低谷/深谷） |

## 数据模式术语

| 术语 | 说明 |
|------|------|
| SQLite 模式 | 使用 SQLite 数据库作为数据源，需运行后端 API 服务 |
| CSV 模式 | 前端直接读取静态 CSV 文件，无需后端服务，可部署到静态站点 |
| config.json | 配置文件，控制数据源模式切换 |
