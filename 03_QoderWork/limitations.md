# 已知限制说明

## 一、数据覆盖限制

### 1.1 省份范围
- 本 MVP 仅覆盖 **广东、江苏、山东、浙江、内蒙古** 5 省（自治区），不构成全国电价全景。
- 各省仅选择了最具代表性的一种用户类型和电压等级（如广东为"一般工商业不满1千伏"），并未穷举所有用户类别。

### 1.2 时段完整性
- **内蒙古**：未找到明确的尖峰/深谷电价时段划分和浮动比例。内蒙古属于电力多边交易市场，电价机制与电网代购电省份不同，部分数据为估算值，以官方公告为准。
- **浙江深谷**：仅适用于春节、劳动节、国庆节前三天，其他节假日深谷政策待补充。
- **广东深圳**：深圳执行独立电价体系，数据未包含在珠三角数据中。

### 1.3 价格精度
- 电价每月随代理购电价格波动调整，本项目中数据为 **2026年最近可获取月份** 的价格快照，不代表当前实时价格。
- 江苏省2026年7月起不再执行迎峰度夏尖峰深谷电价（据公开报道），数据可能已滞后。

## 二、技术限制

### 2.1 SQLite 模式
- 当前静态演示使用 CSV 模式，CSV 模式无需后端即可运行。
- SQLite 模式需要本地运行 HTTP 服务器并支持 SQLite 数据库连接，在 GitHub Pages 上无法运行 SQLite 模式。
- SQLite 模式下，`import_csv.py` 脚本需用户自行编写或参考 `sql/init.sql` 中的结构手动导入。

### 2.2 数据更新
- 本项目为静态数据展示，不包含自动爬取能力。
- 各月度代理购电价格更新后，需要手动更新 CSV 文件中的数据。

### 2.3 浏览器限制
- 使用 `file://` 协议直接打开时，浏览器可能因 CORS 限制无法加载 CSV 文件。
- 建议使用 `npx serve` 或 `python -m http.server` 启动本地 HTTP 服务后访问。

## 三、数据来源限制

### 3.1 间接引用
- 部分数据来源于行业媒体转载（如北极星储能网、索比光伏网），而非原始政府公告原文。
- 对于这些数据，已在 sources.csv 中标注可信度为"中"。

### 3.2 价格组成
- 工商业用户的到户电价由 **代理购电价格 + 输配电价 + 政府性基金及附加 + 系统运行费** 等多部分构成。
- 分时电价浮动仅影响部分电价组成，并非全部。本项目展示的价格为综合到户价，可能与用户的签约市场电价存在差异。

### 3.3 区域差异
- 各省内部不同地市、不同电压等级的电价存在差异。
- 广东仅覆盖珠三角五市，山东以省级政策为主，内蒙古区分蒙西/蒙东两个电网区域。

## 四、后续改进建议

1. **扩展省份覆盖**：增加四川、河南、湖北等用电大省数据
2. **自动化数据采集**：建立定时任务从各省发改委网站抓取月度价格公告
3. **SQLite 后端实现**：开发 Node.js 或 Python 后端，实现 SQLite 模式的真正可用
4. **历史趋势分析**：增加月度价格走势图和同比/环比分析
5. **多元数据维度**：增加居民电价、农业电价等更多用户类型
6. **国际化展示**：增加英文界面支持
