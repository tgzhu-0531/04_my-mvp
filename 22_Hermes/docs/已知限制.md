# 已知限制说明

## 数据限制

### 1. 数据覆盖范围有限
- 当前仅覆盖 5 个样本省份（广东、江苏、山东、浙江、内蒙古），不覆盖全国
- 每个省份仅包含工商业用户（1-10kV）的数据，不含居民、农业、大工业等其他用户类型
- 部分省份仅有省级中心城市数据，未覆盖所有地级市

### 2. 内蒙古数据不完整
- **蒙东电网数据缺失**：内蒙古发改委公开文件主要覆盖蒙西电网区域，蒙东电网（国网供电区域，含赤峰、通辽、呼伦贝尔等）的分时电价数据暂未收录，标注为"待验证"
- 内蒙古数据的可靠性标注为"中"，低于其他四省（均为"高"）

### 3. 价格数据时效性
- 数据采集截止日期为 2025 年 7 月
- 电价政策可能已更新或调整，使用时请以各级政府官网发布的最新文件为准
- 电网公司的代理购电价格每月更新，本站为某个月份的样本数据

### 4. 深谷时段数据
- 部分省份（如山东、浙江）设有深谷时段，但具体的深谷价格数据尚需进一步核实
- 当前数据中深谷分类的时段较少

### 5. 数据精度待验证
- 部分时段价格是基于政策文件中规定的浮动系数计算得出，可能与实际到户电价有差异
- 有些政策文件的文号和具体发布日期尚未完全核实

## 功能限制

### 1. 静态数据无实时更新
- 本站为静态页面，数据需要手动更新（重新运行 `init_db.py` 并重新生成 CSV 文件）
- 暂不支持自动数据采集和实时刷新

### 2. SQLite 模式需要额外服务
- SQLite 模式需要先运行 `scripts/api_server.py` 启动数据接口服务
- 该服务仅用于本地验证，不适合生产环境

### 3. 图表交互有限
- 使用 Canvas 手绘图表，缺乏缩放、悬停提示等交互功能
- 曲线图基于小时粒度采样，精确时段边界展示不够精细

### 4. 无后端搜索功能
- 前端对大量数据的筛选和过滤能力有限
- 没有实现模糊搜索或全文检索功能

### 5. 移动端适配
- 对比表格在窄屏幕下可能需要横向滚动查看
- 部分交互在移动端体验有待优化

## 部署限制

### 1. GitHub Pages
- GitHub Pages 模式下仅支持 CSV 数据源
- 如果 CSV 文件较大，初次加载可能需要一定时间

### 2. Windows IIS
- 需要确保 IIS 配置了正确的 MIME 类型以支持 .json 和 .csv 文件
- 需要启用 UTF-8 编码以避免中文乱码

## 后续优化建议

1. **数据扩展**：增加更多省份和城市的数据，扩展居民和农业用户类型
2. **自动更新**：接入定时数据采集脚本，自动抓取各省发改委和电网公司的最新数据
3. **交互增强**：引入图表库（如 ECharts、Chart.js）提升图表交互体验
4. **搜索功能**：增加全文搜索和数据筛选功能
5. **历史对比**：增加历史价格趋势对比和时间序列分析
6. **API 完善**：将 SQLite API 服务升级为完整的后端服务，支持 RESTful 接口
7. **数据验证**：建立数据交叉验证机制，确保价格数据的准确性
8. **深谷数据**：补充各省深谷时段的具体价格数据
