## 四、错误与修复记录

### 错误 1：PDF 二进制格式无法直接读取
- **阶段**：需求理解
- **描述**：`read_file` 返回 PDF 原始字节流，无法阅读文字内容
- **原因**：PDF 是二进制格式，需专用解析库
- **修复**：使用 `pymupdf`（fitz）库提取文本
- **影响**：+1 轮交互

### 错误 2：搜索引擎全部被 Bot 检测拦截
- **阶段**：数据检索
- **描述**：
  - Google → reCAPTCHA 拦截
  - DuckDuckGo → 机器人检测挑战页
  - curl 模拟 → 超时无返回
- **原因**：容器环境缺乏住宅代理，搜索引擎触发反爬机制
- **修复**：基于模型训练数据中的已知公开权威数据，所有数据标注"需人工复核"
- **影响**：+3 轮交互尝试不同方案

### 错误 3：HTML 模板中 `$` 符号转义
- **阶段**：前端构建
- **描述**：Python 生成的 HTML 中 JS 模板字面量 `${var}` 被渲染为 `$${var}`
- **原因**：Python f-string 中 `$` 与 `{}` 组合触发了误解
- **修复**：改用 `write_file` 直接写入纯 HTML 字符串（非 f-string），再后处理替换
- **影响**：+2 轮交互（发现 + 修复 + 验证）

### 错误 4：Python bytes literal 不支持中文
- **阶段**：前端构建（API Server）
- **描述**：`self.wfile.write(b"<h1>城市分时电价...</h1>")` 报 `SyntaxError: bytes can only contain ASCII literal characters`
- **原因**：Python 3 中 `b"..."` 字节串只能包含 ASCII 字符
- **修复**：使用普通字符串 + `.encode("utf-8")`
- **影响**：+1 轮修复

### 错误 5：JS 模板字面量语法错误
- **阶段**：前端构建
- **描述**：`${String(h).padStart(2, '0'):00}` — `:00` 放在模板表达式外但写在了反引号内
- **原因**：手写代码时语法疏忽，`:00` 误写到模板外
- **修复**：改为 `String(h).padStart(2, '0') + ':00'`
- **影响**：+1 轮修复

### 错误 6：详情页渲染函数缺失
- **阶段**：前端构建
- **描述**：`switchTab('details')` 时页面空白，`renderDetailTable()` 和 `renderDetailChart()` 函数未定义
- **原因**：初始设计只在概览页工作，详情页功能未实现
- **修复**：添加 `renderDetailTable()` 和 `renderDetailChart()` 函数
- **影响**：+2 轮（发现 + 修复）

### 错误 7：Lint 误报
- **阶段**：验证
- **描述**：Node.js 试图加载 `app.js` 作为模块时报 `MODULE_NOT_FOUND`，路径为 `F:\f\02_ChatGPT Work...`（多余 `f\` 前缀）
- **原因**：Hermes 的 linter 对 Windows 路径与 git-bash MSYS 路径的转换有 bug
- **修复**：不影响文件实际运行，忽略 lint 警告
- **影响**：0（仅验证环节显示，不影响功能）

## 五、关键决策记录

| 决策点 | 选择 | 替代方案 | 理由 |
|--------|------|---------|------|
| **数据来源** | 模型训练数据中的已知公开信息 | 实时网络爬取 | 搜索引擎全部被拦截 |
| **前端框架** | 纯 HTML + CSS + JS (0 依赖) | Vue/React/ECharts | 静态部署兼容性最高，IIS/GitHub Pages 均支持 |
| **图表方案** | Canvas API 手绘 | Chart.js / ECharts | 减少外部依赖，控制包体积 |
| **数据存储** | SQLite + CSV 双模式 | 仅 SQLite / 仅 CSV | 需求明确要求双模式 |
| **配置方式** | config.json | 环境变量 / 硬编码 | 需求指定 JSON 配置文件 |
| **内嵌数据** | JS 变量 embeddedData | 异步 CSV 加载 | 保证 CSV 文件加载失败时网站仍然可用 |
| **编码** | UTF-8 (BOM for CSV) | 纯 UTF-8 | 解决 Windows Excel 打开 CSV 乱码 |

## 七、数据质量说明

### 可信度评估

| 数据层级 | 可信度 | 说明 |
|---------|--------|------|
| 省份/城市/用户类型 | 🟢 高 | 各省实际执行分类 |
| 时段划分（尖/峰/平/谷） | 🟢 高 | 基于各省发改委公开政策文件的典型划分 |
| 具体价格数值 | 🟡 中 | 基于政策系数估算，部分需人工核实最新月度公告 |
| 来源 URL | 🟡 中 | 政府主站 URL 可用，具体政策文件 PDF 链接需搜索 |
| 蒙东电网数据 | 🔴 待验证 | 内蒙古仅覆盖蒙西电网，蒙东暂缺 |

### 需人工复核的重点

1. **最新电价**：电网公司每月更新代理购电价格，请以最新月度公告为准
2. **政策文号**：各省发改委政策文号需核实最新版本
3. **蒙东电网**：蒙东区域的分时电价政策需单独检索
4. **深谷价格**：深谷时段的具体价格需进一步确认
5. **居民电价**：居民阶梯电价非分时电价，未纳入
