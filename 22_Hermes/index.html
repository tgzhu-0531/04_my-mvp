方法说明

📄 项目背景

城市分时电价观察站是为验证 AI Work Agent 在真实任务中从需求理解到数据采集、建模、网站开发全链路能力而搭建的 MVP。项目聚焦中国用电量最大的 5 个省份，展示其分时电价政策、时段结构和价格数据。

📈 数据口径

  • 数据范围：广东、江苏、山东、浙江、内蒙古 5 个省份
  • 用户类型：工商业用户（1-10kV），不含居民和农业
  • 电价构成：含电度电价和输配电价，为代理购电用户到户电价
  • 单位：元/kWh（原始来源使用元/千瓦时，本站统一换算）
  • 时段分类：尖峰、高峰、平段、低谷、深谷（标准分类）

📖 数据来源

数据来源于各省（自治区）发展和改革委员会官网公开政策文件，以及国家电网、南方电网、内蒙古电力集团等电网公司发布的代理购电价格公告。具体来源请查看"数据源中心"页面。

⚠ 数据局限性

  • 数据采集时间为 2025 年 7 月，电价政策可能已更新，请以官方最新文件为准
  • 内蒙古仅包含蒙西电网数据，蒙东电网数据暂缺
  • 不同电压等级的电价不同，本站展示的是 1-10kV 等级数据
  • 部分省份夏季和非夏季时段划分不同，已分别标注
  • 实际到户电价可能包含政府基金及附加，具体金额以电网公司账单为准

💻 技术架构

本站采用前端静态页面架构，支持两种数据源模式：通过 config.json 中的 dataSource 字段切换。

  • CSV 模式（默认）：前端直接读取 data/csv/ 目录下的 CSV 文件，无需后端服务，适用于静态托管环境（IIS、GitHub Pages）
  • SQLite 模式：需运行本地数据接口服务，通过 API 读取 SQLite 数据库，适用于本地完整验证
