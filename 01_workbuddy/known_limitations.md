# 已知限制说明

## 1. 数据范围

- 仅覆盖 **5 个样本省份**（广东、江苏、山东、浙江、内蒙古），不具全国代表性
- 内蒙古存在蒙西/蒙东两个电网区域，时段划分不同，网站以蒙西为主
- 主要覆盖 **工商业** 分时电价；居民和农业数据不完整

## 2. 数据时效性

| 政策 | 状态 | 说明 |
|------|------|------|
| 广东省 | 有效 | 粤发改价格〔2021〕331号仍为现行政策 |
| 江苏省 | ✅ 最新 | 苏发改价格发〔2025〕426号，2025年6月1日起执行 |
| 山东省 | ✅ 最新 | 2025年时段划分已公告 |
| 浙江省 | ⚠️ 即将更新 | 已发布2026年新政征求意见稿，实施后将废止旧版 |
| 内蒙古 | 有效 | 2024年2月起执行 |

## 3. 数据缺失

| 缺失项 | 原因 |
|--------|------|
| 广东居民分时电价 | 广东省居民执行阶梯电价，未全面执行分时电价 |
| 江苏居民分时电价 | 2025年政策只涉及工商业 |
| 浙江不满1kV工商业 | 部分用户计量装置尚未完成改造 |
| 蒙东电网具体电价表 | 未发布与蒙西同等详细的电价表 |

## 4. 技术限制

- **CSV 模式**: 纯前端 fetch，受浏览器 CORS 限制，需通过 HTTP 服务器访问（不能用 `file://` 直接打开）
- **IIS 部署**: 需配置 `.csv` 文件的 MIME 类型为 `text/csv; charset=utf-8`
- **图表**: 依赖 Chart.js CDN，离线环境不可用
- **搜索**: CSV 模式下搜索过滤为前端全量加载，数据量大时影响性能

## 5. 口径差异说明

不同省份对大工业/一般工商业的划分标准不同，跨省对比时需注意：

- **广东**: 全省统一时段，工商业统一执行
- **江苏**: 两部制 vs 单一制浮动比例不同（峰 80% vs 70%）
- **山东**: 五段式（尖/峰/平/谷/深谷），按月/季分不同时段
- **浙江**: 大工业 vs 一般工商业浮动比例不同
- **内蒙古**: 按风力发电特性分"大风季/小风季"（与其他省"夏/冬/春/秋"划分逻辑不同）
