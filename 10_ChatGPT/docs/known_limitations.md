# 已知限制

## 1. 数据验证限制

- **网络检索受限**：本次搭建过程中运行环境无法自由访问外网（Google/Bing/政府官网均不可达）。所有电价数据、时段划分和政策文号基于模型训练阶段（截止约2025年初）收录的公开政策文件，而非实时检索结果。
- **价格精度**：各省具体电价（元/kWh）根据政策文件中的峰谷比价和公开的平段代理购电价格计算得出。实际价格因电压等级、用电类别、最新调价等因素可能不同，建议以各省电网公司最新公布的代理购电价格表为准。
- **政策时效性**：部分政策文号（如粤发改价格〔2021〕331号发布于2021年）可能已被更新文件替代，需人工核实。

## 2. 数据覆盖限制

- 本轮仅覆盖 5 个样本省份（广东、江苏、山东、浙江、内蒙古），不涉及全国全量覆盖。
- 内蒙古仅收录蒙西电网数据，蒙东电网参照东北区域电网，具体价格未找到。
- 浙江尖峰时段仅适用于大工业用户，一般工商业暂不设尖峰。
- 除上述 5 省外，其余省份的电价数据均未收录，页面中也不应展示"中国所有省份"的承诺。

## 3. 数据口径限制

- 统一使用"一般工商业 10kV"为示例口径，实际各省对不同电压等级、用电类别的分时电价有不同规定。
- 冬季/夏季尖峰时段差异较大，页面默认展示"通用"季节或夏季数据。用户需在查看时注意季节前提。
- 居民分时电价未纳入本轮数据范围。

## 4. 技术限制

- SQLite 模式需要额外搭建后端 API 服务才能工作，当前仓库默认使用 CSV 模式。
- 当前未提供开箱即用的 SQLite API 服务，仅提供了数据库初始化脚本和导入脚本。
- CSV 模式下所有数据在浏览器中加载，大数据量时可能出现性能问题。
- 页面使用 Chart.js CDN，需要互联网连接才能加载图表库。建议在 IIS/内网环境下预先下载 Chart.js 到本地。

## 5. 网站功能限制

- 当前为纯前端 SPA 应用，无用户认证和多用户支持。
- 不提供数据导出/下载功能（用户可直接使用 data/ 下的 CSV 文件）。
- 前端路由为简单的显示/隐藏面板切换，未使用 URL 路由（适合静态站点部署）。

## 6. 后续建议

1. **数据更新**：建议定期访问各省发改委官网，获取最新电价政策文件并更新 CSV 数据。
2. **API 服务**：如需要 SQLite 模式，可搭建 Express + better-sqlite3 的轻量 API 服务。
3. **覆盖扩展**：可按省逐步扩展，每次新增一个省份的 CSV 数据和来源记录即可。
4. **自助验证**：可添加"数据贡献"功能，允许用户提交最新政策文件的 URL，经审核后更新数据库。
5. **图表离线化**：如需完全离线运行，将 Chart.js 从 CDN 下载到本地 js/ 目录并修改引用路径。
