# 已知限制说明

## 一、数据限制

### 1. 覆盖范围有限
- 仅覆盖 5 个样本省份（广东、江苏、山东、浙江、内蒙古），不反映全国情况
- 每个省份仅选取了 1-2 个代表性城市，未涵盖所有地级市
- 内蒙古以蒙西电网为代表，蒙东电网的时段划分和价格不同
- 未覆盖农业用电、贫困县优惠电价等特殊类别

### 2. 价格时效性
- 部分省份的月度代理购电价格每月更新，本网站展示的价格为代表性月份的数据
- 山东深谷价格基于下浮90%的比例计算，实际月度价格因基价波动会略有不同
- 江苏省统一平段基价 0.80 元/kWh 为参考值，各市略有差异
- 实际用户到户电价还包含输配电价、政府基金及附加，与展示的浮动电度电价不完全一致

### 3. 缺失数据
- 广东省未设置深谷时段，江苏、内蒙古（蒙西）未设尖峰/深谷分类
- 浙江省春秋季不设尖峰时段
- 江苏省精确平段基价未找到省级统一官方发布，当前使用参考值
- 居民分时电价政策差异较大，本版本以工商业为主

### 4. 数据来源限制
- 部分政策文件为转载来源，原始文件链接可能因政府网站改版而失效
- 价格数据来自电网公司代理购电公告，大用户直接购电价格可能不同
- 部分省份政策存在征求意见稿和正式稿的差异，以正式稿为准

## 二、功能限制

### 1. CSV 模式限制
- 浏览器安全策略禁止直接读取本地文件，必须通过 HTTP 服务器访问
- CSV 文件不支持动态查询，筛选功能在前端完成，数据量小时性能良好
- 无法在 CSV 模式下使用 SQL 查询功能

### 2. SQLite 模式限制
- 需要安装 Node.js 和 npm 依赖
- 需要先通过 Python 脚本导入数据
- 数据库文件需要手动初始化

### 3. 前端限制
- 图表为静态渲染，不支持交互式数据筛选（如切换季节、电压等级）
- 未实现省级部门联动查询（如选择省份后自动过滤城市）
- 未实现价格趋势预测或历史对比分析

## 三、部署限制

### 1. 静态部署
- GitHub Pages 部署时需确保所有文件路径为相对路径
- IIS 部署时需配置 UTF-8 编码和 MIME 类型
- 需要手动修改 config.json 中的 dataSource 配置

### 2. 本地运行
- 必须通过 HTTP 服务器访问，不能直接双击打开 HTML 文件
- 建议使用 Python 的 http.server 或 Node.js 的 http-server
