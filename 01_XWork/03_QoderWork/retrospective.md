## 六、关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 前端框架 | 原生 HTML + CSS + JS | 无依赖、零构建、GitHub Pages 直接用 |
| 图表库 | Chart.js 4.4.1 CDN | 轻量、柱状图/对比图原生支持 |
| 数据格式 | CSV（主） + SQLite（辅） | CSV 适配静态部署，SQLite 适配本地验证 |
| 架构 | 单页应用（SPA） | 所有功能集中在 index.html，路由通过 JS 控制 |
| PDF 读取 | PyMuPDF 转图片 → Read 视觉识别 | pypdf/pdfplumber CJK 编码损坏时的兜底方案 |
| 设计风格 | 深色导航 + 浅色内容 + 明亮色块 | 符合"简约、亮眼、适合数据查询"要求 |

## 七、遇到的问题 & 解决

| 问题 | 原因 | 解决 |
|------|------|------|
| PDF 中文乱码 | 字体编码 (SimHei) ToUnicode 映射缺失 | PyMuPDF 转 PNG → Read 工具视觉读取 |
| 各省电价数据分散 | 无统一公开 API | 逐省搜索、逐页面 Fetch 提取 |
| 部分省份价格缺失 | 数据未公开或格式复杂 | 标记为缺失数据，在 limitations.md 说明原因 |
| 浏览器 CORS 限制 | file:// 协议下 fetch CSV 被拦截 | 建议使用 HTTP 服务（npx serve / python -m http.server） |
| dataSource 模式指示器不更新 | HTML 写死标签，JS 未读取 config | 改为动态读取 + 实时渲染 |

## 八、后续优化建议

1. **自动化数据采集**：建立定时任务（如 GitHub Actions）每月从各省发改委自动抓取最新代理购电价格
2. **SQLite 后端真正可用**：开发 Node.js 或 Python 后端 API 服务，实现 SQLite 模式的完整链路
3. **扩展省份**：增加四川、河南、湖北、安徽等用电大省
4. **历史趋势分析**：保存多个月份快照，展示价格变化趋势
5. **多用户类型**：增加居民电价、农业电价、大工业不同电压等级的数据维度
6. **国际化**：添加英文界面，支持外文用户查询中国分时电价政策
