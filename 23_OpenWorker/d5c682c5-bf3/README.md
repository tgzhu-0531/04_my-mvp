> **TOU Electricity Price Observatory**  
> 查询并对比中国主要城市的分时电价数据，追溯官方数据来源。

## 📋 项目概述

**城市分时电价观察站** 是一个专注于中国城市 **分时电价（TOU, Time-of-Use）** 数据查询与对比的信息平台。  
MVP 版本覆盖 **10 个城市** 的分时电价数据，提供四个核心功能页面：

| 页面 | 功能 |
|------|------|
| 📊 **总览** | 统计概览、城市高峰电价柱状图、年度趋势折线图、城市网格 |
| 🔍 **查询** | 按城市/时段/电压等级筛选电价、查看分时时段定义 |
| 📈 **对比** | 多城市（最多5个）尖峰/高峰/平段/低谷电价横向对比 |
| 📋 **来源** | 完整的数据来源清单，含可靠性评分和原文链接 |

## 🚀 快速开始

### 环境要求

- Python 3.10+
- pip / pip3

### 1. 安装依赖

```bash
pip install fastapi uvicorn aiofiles sqlite3
```

> 注：sqlite3 是 Python 标准库，无需额外安装。

### 2. 初始化数据库

```bash
python init_db.py
```

执行后将在 `data/` 目录创建 `electricity_prices.db`，包含：
- 10 个城市基础信息
- 各城市分时电价记录（132条）
- 分时时段定义
- 年度趋势数据
- 33 个数据来源

### 3. 启动服务

```bash
python backend/main.py
```

### 4. 访问网站

浏览器打开 **[http://127.0.0.1:8090](http://127.0.0.1:8090)**

## 🔌 API 文档

启动服务后，自动生成交互式 API 文档：

| 地址 | 说明 |
|------|------|
| `/docs` | Swagger UI 交互式文档 |
| `/redoc` | ReDoc 文档 |

### 核心 API 端点

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/cities` | 获取所有城市列表 |
| GET | `/api/cities/{id}` | 获取单个城市详情 |
| GET | `/api/prices?city_id=&period=&voltage=` | 查询电价（支持多维度筛选） |
| GET | `/api/prices/compare?cities=1,2,3` | 多城市电价对比 |
| GET | `/api/price-periods/{city_id}` | 获取城市分时时段定义 |
| GET | `/api/trends/{city_id}` | 获取城市年度价格趋势 |
| GET | `/api/sources` | 获取数据来源清单 |
| GET | `/api/stats` | 获取统计概览 |

## 🤝 贡献指南

1. 添加新城市：在 `backend/seed_data.py` 中补充城市信息和电价数据
2. 添加数据来源：在 `SOURCES` 列表和 `PRICE_DATA` 中补充
3. 更新电价：修改 `PRICE_DATA` 中的价格数值和 `effective_date`
