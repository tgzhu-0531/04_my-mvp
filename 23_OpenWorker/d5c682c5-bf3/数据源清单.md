# 城市分时电价观察站 — 数据源清单

## 数据来源总览

所有电价数据均来源于各省市 **发改委（物价局）官方公告** 及 **电网公司公开信息**。  
每条电价记录均可追溯到其对应的数据来源。

## 数据采集方式

- **方式1**: 直接采集各地发改委官网 PDF 公告
- **方式2**: 国家电网/南方电网客服系统公示电价
- **方式3**: 省级电力交易中心公开数据

## 数据字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 城市名称 | 地级市名称 | 北京 |
| 省份 | 所属省/直辖市 | 北京 |
| 区域 | 地理大区（华北/华东/华南等） | 华北 |
| 电网公司 | 管辖电网企业 | 国家电网 |
| 时段名称 | 尖峰/高峰/平段/低谷 | 高峰 |
| 电压等级 | 1-10kV / 35kV及以上 / 不满1kV | 1-10kV |
| 电价 | 单位：元/kWh | 1.1802 |
| 生效日期 | 该价格生效起始日期 | 2025-01-01 |
| 数据来源 | 对应的官方来源名称 | 北京市发展和改革委员会 |
| 可靠性评分 | 1-5分，政府官网默认5分 | 5 |
