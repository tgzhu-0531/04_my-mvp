# 城市分时电价观察站 — 已知限制

> 最后更新: 2025年7月  
> 本文档列出了当前 MVP 版本的功能局限和已知问题，供迭代优化参考。

---

## 🎯 功能限制

### 1. 数据覆盖范围有限

| 维度 | 当前 | 期望 |
|------|------|------|
| 城市数量 | 10个 | 覆盖所有地级市（300+） |
| 电压等级 | 主要支持1-10kV | 含不满1kV、35kV、110kV等多等级 |
| 用户类型 | 一般工商业 | 增加大工业、农业、居民阶梯电价 |
| 季节性 | 上海有夏/非夏区分 | 所有城市标注季节性浮动 |

### 2. 数据更新机制

- **当前**：数据为静态种子数据，需手动修改 `seed_data.py` 后重新初始化
- **期望**：自动抓取各地发改委公告 + 定期更新提醒
- **解决**：可通过 CSV/JSON 导入接口批量更新（API 预留 `POST` 接口）

### 3. 用户系统缺失

- 无登录/注册功能
- 无收藏、对比记录保存
- 无订阅（某城市电价变动通知）

### 4. 数据对比维度有限

- 仅支持横截面对比（多城市同一时段）
- 不支持时间序列对比（同一城市不同年份的完整对比）
- 不支持时段时间表可视化（24h 时段色带图）

### 5. 缺乏数据导出

- 不支持 CSV/Excel 导出
- 不支持图表截图下载

### 6. 趋势数据仅覆盖 3 个城市

- 仅北京、上海、广州有 2021-2024 年度趋势数据
- 其他城市暂缺历史数据

---

## 🐛 已知技术问题

### 1. 静态文件路径

- 前端资源通过 `/static/` 前缀访问（`/static/css/style.css`）
- 根路径 `/` 由独立路由提供
- **影响**：刷新非根路径页面时可能 404

### 2. GBK 编码兼容

- Windows 中文环境下控制台输出含 Unicode 字符（如 ✓）可能报错
- **解决**：已在 `main.py` 中设置 `sys.stdout` 为 UTF-8 编码

### 3. SQLite 并发

- SQLite 不适合高并发写入场景
- MVP 阶段无此问题，生产化需迁移至 PostgreSQL

### 4. 前端未做移动端深度适配

- 基本响应式（CSS Grid 自适应）
- 但表格组件在小屏设备上需要横向滚动
- 图表在 ≤400px 宽度下显示拥挤

### 5. 浏览器兼容性

- 使用 ES6+ 语法，不支持 IE 11
- 推荐 Chrome / Edge / Firefox 最新版本

### 6. 无 HTTPS 支持

- 仅 HTTP 明文传输
- 生产环境前置 Nginx/Caddy 反代
