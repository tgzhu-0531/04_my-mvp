# 已知限制说明

## 1. 电价数值限制

### 1.1 仅山东有具体到户电价

山东省在2025年4月新闻发布会中公布了35千伏一般工商业的具体示例电价（尖峰1.20、峰1.00、平0.71、谷0.35、深谷0.25元/kWh），是全国唯一公布完整五段式具体电价的省份。

其他4省（广东、江苏、浙江、内蒙古）均采用浮动比例机制，电价随月度代理购电价格浮动，无法固定单一数值。

### 1.2 浮动比例换算说明

首页对比图表中，非山东省份的电价数据为按浮动比例估算的参考值，以山东平段0.71元/kWh为参考基准换算，仅供对比参考，非实际到户电价。

实际到户电价需查询各省电网公司月度发布的代理购电价格。

## 2. 数据覆盖限制

### 2.1 用户类型覆盖

本MVP以"工商业"用户为统一口径，暂未完整覆盖居民分时电价和农业生产分时电价数据。

- 广东: 居民用户可自主选择执行峰谷分时电价
- 江苏: 居民生活用电实行峰谷分时电价和阶梯电价
- 山东: 居民分峰谷两段（峰0.58元/度、谷0.37元/度为参考值）
- 浙江: 本次政策未涵盖居民用户，另行制定
- 内蒙古: 居民分时电价政策未在本次工商业文件中涵盖

### 2.2 电压等级覆盖

本MVP主要覆盖1-10千伏电压等级（山东为35千伏示例），暂未完整覆盖所有电压等级的电价差异。

### 2.3 内蒙古分区

内蒙古因蒙西电网和蒙东电网分属不同电网公司，电价政策不同，已拆分为两条记录。但同一电网内不同盟市的具体执行可能存在差异，未逐一覆盖。

## 3. 时效性限制

### 3.1 数据采集时间

所有数据采集日期为2026-07-25。政策可能在此日期后更新。

### 3.2 山东动态调整

山东分时电价实行动态调整机制，每年11月公布次年时段，年内可提前1个月调整。本MVP使用的是2025年4月发布的示例时段。

### 3.3 浙江新政

浙江省浙发改价格〔2026〕112号于2026年7月1日起执行，为本MVP采集时最新政策。

## 4. 技术限制

### 4.1 CSV 模式下无后端筛选

CSV 模式下所有筛选在前端完成，数据量较大时可能影响性能。当前数据量（71条记录）不影响使用。

### 4.2 SQLite 模式需 Python 环境

SQLite 模式需要本地安装 Python 3.x（无需第三方库），启动后端服务后才能访问。

### 4.3 Chart.js 依赖 CDN

图表库 Chart.js 通过 CDN 加载，离线环境下图表无法显示。页面其他功能不受影响。

### 4.4 浏览器兼容性

推荐使用 Chrome、Edge、Firefox 等现代浏览器。不支持 IE 11 及以下版本。

## 5. 数据完整性限制

### 5.1 缺失数据项

共有10条缺失数据记录，主要涉及：
- 各省工商业具体到户电价数值（因代理购电价格按月浮动）
- 各省居民分时电价具体数值（因不在本次工商业政策覆盖范围）

详见网站"缺失数据"页面。

### 5.2 政策文号完整性

部分省份的政策文件通过地市级政府网站转载获取原文，未直接访问到省级发改委官网原文页面，但转载内容与原文一致。

## 6. 后续建议

1. **增加月度代理购电价格数据**: 可定期从各省电网公司官网抓取月度代理购电价格，计算出实际到户电价
2. **扩展居民分时电价**: 补充各省居民分时电价政策和具体电价
3. **增加更多省份**: 在5省基础上扩展至全国
4. **增加历史数据**: 记录政策变更历史，展示电价调整趋势
5. **增加电压等级维度**: 补充不同电压等级的电价差异
6. **离线 Chart.js**: 将 Chart.js 下载到本地，支持离线使用
