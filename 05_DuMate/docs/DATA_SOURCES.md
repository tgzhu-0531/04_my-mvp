## 来源可信度评估标准

| 等级 | 标准 |
|------|------|
| 高 | 省级发改委官网原文、政府门户网站、国家电网/南方电网官网 |
| 中 | 地市级政府网站转载省级文件、电力交易中心公告 |
| 低（不采用） | 商业整理内容、无来源标注的转载文章、无发布时间的网页 |

本项目中所有来源均为"高"等级。
