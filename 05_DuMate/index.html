一句话分析结论
山东是全国唯一公布完整"五段式"具体电价（尖峰1.20、峰1.00、平0.71、谷0.35、深谷0.25元/kWh）的省份，峰谷价差达0.95元/kWh，居五省之首；广东、江苏、浙江、内蒙古均采用浮动比例机制（基准价按月浮动），其中浙江峰谷浮动比最高达10.25:1（2.05:0.2），理论上峰谷价差最大但实际价格随月度波动。

方法说明

本观察站的数据采集、结构化和展示方法。

数据来源规则

  • 优先使用省级或地市级发展改革委官网、能源主管部门官网
  • 使用国家电网、南方电网及其省级电力公司官网
  • 使用政府公开公告、政策文件、价格表、PDF 附件
  • 不建议使用未标注来源的二次转载文章、无发布时间或发布机构的网页

口径说明

  • 本项目以"工商业"用户为统一口径，不混用居民电价、工商业电价、代理购电价格
  • 电价单位统一为元/kWh，原始来源使用其他单位的已换算
  • 区分省份、城市/区域、用户类型、电压等级、季节类型、分时时段、起止时间
  • 每条记录包含政策生效日期、来源 URL、发布机构、发布时间、采集时间和口径说明

时段标准分类

  • 尖峰: 最高电价时段，通常仅在夏季/冬季高峰或极端高温日执行
  • 峰: 高电价时段，引导用户避峰用电
  • 平: 基准电价时段，电价接近平均供电成本
  • 谷: 低电价时段，引导用户填谷用电
  • 深谷: 最低电价时段，通常在午间光伏大发时段执行（山东首创）
  • 不同省份的时段划分不同，不能假设全国统一

数据状态说明

  • 真实数据: 来源于省级发改委官网公开政策文件，可追溯
  • 缺失数据: 因政策机制原因无法获取固定数值，已标注原因
  • 本项目不使用任何 mock 数据冒充真实数据
  • 山东电价为官方新闻发布会公布的示例电价（2025年4月35千伏一般工商业），其他省份为浮动比例

双数据源架构

  • CSV 模式: 静态展示场景，前端直接读取 CSV 文件，适用于 IIS / GitHub Pages
  • SQLite 模式: 本地完整验证场景，通过 Python HTTP 服务读取数据库
  • 通过 config.json 切换数据源，同一套前端代码。当前模式: CSV
  • 两种模式下页面展示、筛选查询、来源追溯行为完全一致
