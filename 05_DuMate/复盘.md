- 🧠 **大模型推理**：判断数据来源可信度——优先省级发改委官网原文，排除商业整理内容和无来源转载；识别各省政策差异（山东五段式具体电价 vs 其他四省浮动比例机制）；内蒙古需按蒙西/蒙东电网分区

## 五、经验教训与总结

### 做得好的

1. **零第三方依赖架构选型**：前端纯原生 HTML/CSS/JS，后端 Python 标准库，SQLite 内置于 Python。用户环境无需 pip install 任何包即可运行，极大降低了部署门槛和复现成本。PRD 要求"能在 Windows IIS 和 GitHub Pages 静态运行"，这一选型完美匹配。

2. **数据来源全部可追溯**：8 条来源全部来自省级发改委官网原文，每条电价记录关联到来源 ID，前端页面每条数据都展示来源链接和发布机构。PRD 明确禁止"不得编造任何电价数据"，本项目中 0 条无来源数据，10 条缺失数据也做了透明标注。

3. **双数据源抽象层设计**：`data.js` 封装了 CSV 和 SQLite 两种数据源的读取逻辑，上层 `app.js` 完全不感知数据源差异。切换模式只需修改 `config.json` 一个字段，符合 PRD"不得把数据源模式写死在代码中"的要求。

4. **缺失数据透明化**：独立设计 `missing_data` 表和页面，明确记录哪些数据获取不到、原因是什么、下一步建议怎么做。10 条缺失记录覆盖了各省具体到户电价（因代理购电月度浮动）和居民电价（不在本次工商业覆盖范围）等。

5. **首页面向业务用户**：首页未展示技术配置信息（数据源模式、编码方式），而是聚焦业务关心的内容——覆盖省份概览、Top5 峰谷价差对比、一句话分析结论、数据来源入口。符合 PRD"首页应面向普通业务用户而非开发者"。

### 做得不够的

1. **CSV 解析类型安全缺陷**：3 个 Bug 中有 2 个源于 JavaScript 弱类型 + CSV 解析后的数字/字符串混合——空价格字段导致 `.toFixed()` 抛异常，`province_id` 数字与字符串 `===` 比较失败。根因是数据层未在解析时统一完成类型转换和空值处理，将类型不安全的风险扩散到了渲染层。应在 `data.js` 的 CSV 解析阶段就做好类型标准化（String/Number/null 分类转换），而非依赖各调用点各自防护。

2. **行政区域表未到省市区三级**：PRD §8 明确要求"行政区域表需要包含省、市、区三级信息"，实际只做了省级 + 内蒙古蒙西/蒙东分区，未细化到地市级。虽然 5 省工商业电价大多省级统一执行，但内蒙古同一电网内不同盟市执行可能存在差异，未覆盖这一层级。

3. **首页对比含估算值未充分提示**：非山东省份的电价按浮动比例以山东平段 0.71 元/kWh 为基准估算，首页柱状图和一句话结论基于这些估算值。虽然在"已知限制"文档中做了说明，但首页图表区域本身缺乏醒目的"估算参考值"标注，业务用户可能误读为实际到户电价。

4. **方法说明页面静态文本未联动**：Bug #3 暴露了文档类页面（方法说明）中的数据源模式信息是硬编码的静态文本，未与 `config.json` 联动。这类"看似动态实为静态"的内容是前端 SPA 中容易遗漏的角落，应在初始化时统一扫描所有需要动态更新的元素。

5. **Chart.js CDN 依赖未做离线降级**：图表库通过 CDN 加载，离线环境下图表不显示但无降级方案。可以在 `<script>` 标签加 `onerror` 回退到本地文件，或检测 CDN 加载失败后用纯 CSS/Canvas 绘制简易柱状图替代。

### 后续改进建议

1. **数据层类型安全框架化**：在 `data.js` 中实现统一的类型转换管道——CSV 解析时按字段 schema 定义（`province_id: int`、`price_yuan_kwh: float|null`、`source_url: string`）自动转换，避免弱类型问题向下游扩散。后续项目应将这一模式固化为通用 CSV 解析模块。

2. **行政区域表补充地市级数据**：优先补充内蒙古蒙西/蒙东电网覆盖的主要盟市（如呼和浩特、包头、赤峰、通辽），以及广东的珠三角五市、江苏的苏南苏北差异区域，满足 PRD 省市区三级要求。

3. **首页估算值可视化区分**：在柱状图中对估算值使用半透明/斜线纹理填充，与山东省实际电价的实心柱形成视觉区分；图表标题或图例中增加"部分数据为浮动比例估算参考值"提示。

4. **离线 Chart.js 降级方案**：将 `chart.umd.min.js` 下载到 `assets/vendor/` 目录，`<script>` 标签先尝试 CDN，`onerror` 时加载本地副本；或用纯 Canvas API 实现一个无依赖的简易柱状图组件。

5. **月度代理购电价格自动更新**：设计一个定时任务（可用 scheduler），每月从各省电网公司官网抓取最新代理购电价格，自动计算出实际到户电价并更新数据库，解决"非山东省份无固定电价"的核心限制。

6. **自动化测试**：为数据层和渲染层编写基础测试——CSV 解析的正确性（空值/类型/行数）、筛选逻辑的准确性（省份/用户类型/季节组合）、图表渲染不抛异常。3 个 Bug 均可通过前置测试预防。
